# Wheat-Heat-Stress-Analysis
Morpho-physiological, biochemical, and Molecular evaluation of wheat genotypes under heat stress using R.

This repository contains data analysis and visualization workflows used to evaluate wheat genotypes under heat stress conditions. The study integrates phenotypic, physiological, and biochemical traits to identify heat-tolerant genotypes.
Objectives
Evaluate genotype performance under heat stress
Analyze physiological and biochemical responses
Identify traits associated with heat tolerance
Tools
R
RStudio
Excel
Outputs
ANOVA tables
Correlation analysis
PCA plots
Publication-quality figures
